# 資料、快取、加密與備份 Profile v4.4

本 Profile 實作 `DATA-REQ-001～004`，不得用另一套模型替換來源。

## 快取

經常性資料使用快取並設定持久化，使系統重新啟動後能延續未完行為。可額外使用 Durable Store、Checkpoint 與 Job State 提高可靠性，但不得刪除快取持久化要求。

## 三層金鑰

1. 管理員金鑰：加密租戶資料。
2. 租戶金鑰：加密該租戶客戶資料。
3. 客戶金鑰：加密自己的資料。

每一角色帳號建立時產生其金鑰；提示擁有者自行保存；只顯示一次；DB 內由上級管理者金鑰加密；無租戶時由系統管理者金鑰加密；系統管理者金鑰以 Runtime 環境變數提供。KMS／HSM／Secret Manager 可保護與注入環境變數，不得改變角色層級與一次顯示行為。

## 驗證與備份

- 輸入與輸出均經鏈式合法性、完整性、業務規則與系統預期驗證。
- 提供資料庫備份；下載開關由系統管理員控制且角色繼承；產生角色／租戶範圍內的可下載備份資料，並測試無越權。
- 備份具加密、完整性、Retention、Restore Test 與 Audit。
