# v4.4 修正報告

## 問題

v4.3 把第 22、23 章寫成 Linux 與 Microsoft .NET／C# 技術剖面，偏離「研究大型工程團隊公開規範並轉成通用開發行為」的目的；原有前端 Profile 又只列出產品 UI 功能，缺少完整前端工程基準。

## 修正

1. 第 22 章改為通用開發變更、可讀性、可維護性與 Agent 行為。
2. 第 23 章改為通用程式實作、執行、資源、安全、Build 與交付品質。
3. 新增第 24 章前端開發基準。
4. 移除核心 Linux、.NET、Vue／Nuxt 技術採用 Profile 與平台政策。
5. 新增 Always-on 通用 Profile 與框架中立前端 Profile。
6. 新增完整 70 項前端控制與分階段測試／審查。
7. 主規範與獨立載入檔使用完全一致的 GDB／GIQ／FED Control ID 與規範文字，禁止同一 ID 產生不同語意。
8. 驗證器新增技術中立、前端基準、主檔／參考檔一致性與舊 Profile 不得存在等檢查。

## 不變項目

57 項產品負責人不可變需求、來源文字、Requirement ID、強度與 Baseline Digest 均未修改。
