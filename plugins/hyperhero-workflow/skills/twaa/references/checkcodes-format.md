# TWAA 檢測碼與稽核評量碼格式說明

> 資料來源：數位發展部無障礙網路空間服務網 — 網站無障礙規範(110.07)
> 本文件供系統開發人員解讀退件報告、對應修正項目使用。

---

## 前言

本規範之 **4 原則、13 指引及 78 成功準則**，針對網頁科技之變動，將適時修改及調整檢測碼（C 碼）與稽核評量碼（E 碼）。

---

## 一、檢測碼（C 碼）格式

> **定義：** 可用自動化軟體工具檢測，結果為通過或失敗。
> **格式：** `XX` + `1234567` + `C`（共 10 碼）

### 範例：`HM1110100C`

| 位置 | 值 | 說明 |
|------|----|------|
| 第 1-2 碼（文字） | `HM` | 網頁科技前綴（HTML） |
| 第 3 碼（數字） | `1` | 檢測等級（1=A, 2=AA, 3=AAA） |
| 第 4 碼（數字） | `1` | 原則編號（對應成功準則第一碼） |
| 第 5 碼（數字） | `1` | 指引編號（對應成功準則第二碼） |
| 第 6-7 碼（數字） | `01` | 成功準則編號，從 01 起（對應第三碼） |
| 第 8-9 碼（數字） | `00` | 流水號（同一準則下第幾個，從 00 起） |
| 第 10 碼（文字） | `C` | 類型：C = 可自動檢測 |

### 解碼範例

| 檢測碼 | 解碼 |
|--------|------|
| `HM1110100C` | HTML + Level A + 成功準則 1.1.1 + 第 00 個 |
| `CS2140401C` | CSS + Level AA + 成功準則 1.4.4 + 第 01 個 |
| `GN2330300C` | General + Level AA + 成功準則 3.3.3 + 第 00 個 |

---

## 二、稽核評量碼（E 碼）格式

> **定義：** 需由人工稽核，無法以軟體完全自動判定。
> **格式：** `XX` + `1234567` + `E`（共 10 碼）

結構與 C 碼完全相同，差異只在第 10 碼：
- `C` = 自動檢測
- `E` = 人工稽核

### 範例：`HM1240200E`

| 位置 | 值 | 說明 |
|------|----|------|
| 第 1-2 碼 | `HM` | HTML |
| 第 3 碼 | `1` | Level A |
| 第 4-7 碼 | `2402` | 成功準則 2.4.2（網頁標題） |
| 第 8-9 碼 | `00` | 第 00 個稽核評量碼 |
| 第 10 碼 | `E` | 人工稽核 |

## 四、等級對照

| 第 3 碼數字 | 檢測等級 | 說明 |
|------------|---------|------|
| `1` | A | 最低等級，必須滿足 |
| `2` | AA | 標章申請要求等級 |
| `3` | AAA | 最高等級 |

---

## 五、成功準則編碼解析規則

第 4-7 碼（4 位數字）對應成功準則編號，規則如下：

```
成功準則 X.Y.ZZ → 數碼 = XYZZ（Y.ZZ 各佔 1 碼，ZZ 從 01 起）

範例：
  1.1.1  → 1101
  1.4.3  → 1403
  2.4.2  → 2402
  3.3.2  → 3302
  3.3.3  → 3303
```

## 七、如何使用查碼工具

```bash
# 在 twaa skill 目錄下執行
python scripts/lookup_checkcode.py GN1240100E    # 查單一代碼完整說明
python scripts/lookup_checkcode.py 2.4.1         # 查某成功準則所有代碼
python scripts/lookup_checkcode.py --list AA     # 列出所有 AA 等級代碼

# 自動解碼任何代碼（含未收錄於規範文件的代碼）
python scripts/decode_checkcode.py HM1240402E
```
