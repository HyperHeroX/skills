# HM1240400C 連往相同資源的毗鄰圖片與文字，其由文字內容及替代文字產生之鏈結文字只能有一份

- **檢測碼**：HM1240400C
- **對應成功準則**：2.4.4
- **對應認證等級**：A
- **對應國際技術碼**：H2
- **類別**：HTML
- **訊息**：連往相同資源的毗鄰圖片與文字，其由文字內容及替代文字產生之鏈結文字只能有一份
- **英文訊息**：H2: Combining adjacent image and text links for the same resource

## 規則說明

如果相鄰的圖片和文字超連結都是連往相同的資源，必須將超連結合併使用，且圖片 alt 屬性必須是空值或不可重複連結文字的內容，通過檢測，否則檢測失敗。

## 範例

**範例1：圖片 alt 為空值，文字已說明連結目的**
```html
<a href="foo.htm">
  <img src="house.gif" alt=""/>回去首頁
</a>
```

**範例2：圖片 alt 提供補充資訊，與文字區分**
```html
<a href="foo.pdf" title="檔案名稱">
  <img src="pdf.gif" alt="pdf檔案"/>點我下載
</a>
```

## 說明

**範例1**：範例為一個回去首頁的圖示與文字超連結，文字內容已經是「回去首頁」，所以 `<img>` 標籤中的 alt 屬性就不再多做設定。

**範例2**：範例為一個檔案下載的圖示與文字超連結，檔案類型使用圖示表示並未描述在文字內容，所以 `<img>` 標籤中的 alt 屬性顯示為「pdf檔案」，並與連結文字區分。
