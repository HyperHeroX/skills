# HM1240200C 網頁需有標題組件，且其值不得為空字串或空白

- **檢測碼**：HM1240200C
- **對應成功準則**：2.4.2
- **對應認證等級**：A
- **對應國際技術碼**：G88、H25
- **類別**：General
- **訊息**：網頁需有標題組件，且其值不得為空字串或空白
- **英文訊息**：G88: Providing descriptive titles for Web pages / H25: Providing a title using the title element

## 規則說明

如果 `<title>` 標籤內容不為空字串或空白，通過檢測，否則檢測失敗。

## 範例

```html
<head>
  <title>台北車站站前廣場</title>
</head>
<body>
  ...
</body>
```

## 說明

`<title>` 標籤中的內容為「台北車站站前廣場」，標籤有值，不為空字串或空白。
