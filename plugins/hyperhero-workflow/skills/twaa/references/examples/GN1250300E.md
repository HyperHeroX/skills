# GN1250300E 確保無障礙名稱包含可見文字

- **稽核評量碼**：GN1250300E
- **對應成功準則**：2.5.3
- **對應認證等級**：A
- **對應國際技術碼**：G208
- **類別**：General
- **訊息**：確保無障礙名稱包含可見文字
- **英文訊息**：G208: Including the text of the visible label as part of the accessible name

## 規則說明
確保語音輸入使用者可以可靠地操作網頁內容。 組成可見標籤的文字字符串必須完整地出現在無障礙名稱中。

## 檢測說明
程序

對於具有可見標籤的所有控制元件，檢查：
控制元件的無障礙名稱包含與可見標籤有相同文字且相同順序。

預期結果：#1為是。
