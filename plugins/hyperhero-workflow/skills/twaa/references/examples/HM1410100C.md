# HM1410100C 網頁完全符合W3C標準規格，並通過W3C驗證

- **檢測碼**：HM1410100C
- **對應成功準則**：4.1.1
- **對應認證等級**：A
- **對應國際技術碼**：H74、H75、H88、H93、H94、G134、G192
- **類別**：HTML
- **訊息**：網頁完全符合W3C標準規格，並通過W3C驗證
- **英文訊息**：H74: Ensuring that opening and closing tags are used according to specification / H75: Ensuring that Web pages are well-formed / H88: Using HTML according to spec / H93: Ensuring that id attributes are unique on a Web page / H94: Ensuring that elements do not contain duplicate attributes / G134: Validating Web pages / G192: Fully conforming to specifications

## 規則說明

若網頁內含文檔類型聲明（如 `!DOCTYPE` 宣告），且對應到正確 HTML/XHTML 版本，通過檢測，否則檢測失敗。若為 XML 文件需正確宣告 DTD，並通過格式驗證。

## 範例

**範例1：驗證 HTML**

HTML/XHTML 頁面包含文檔類型聲明（有時稱為 `!DOCTYPE` 語句），並且根據文檔類型聲明指定的 HTML 有效版本。

**範例2：驗證 XML**

XHTML、SVG、SMIL 和其他基於 XML 的文檔引用文件類型定義（DTD）或其他類型的 XML 格式。

## 說明

HTML/XHTML 文件通過格式驗證。
