# GN3330603E 在所有情況中，均要求確認後才繼續所選的行動

- **稽核評量碼**：GN3330603E
- **對應成功準則**：3.3.6
- **對應認證等級**：AAA
- **對應國際技術碼**：G168
- **類別**：General
- **訊息**：在所有情況中，均要求確認後才繼續所選的行動
- **英文訊息**：G155: Providing a checkbox in addition to a submit button / G168: Requesting confirmation to continue with selected action

## 規則說明
網站是否有要求確認才能繼續所選的功能。

## 檢測說明
網頁中具有「確認無誤結帳」的功能。

## 說明
無
