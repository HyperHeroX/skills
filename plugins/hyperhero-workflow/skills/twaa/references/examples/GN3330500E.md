# GN3330500E 在所有網頁上均提供協助

- **稽核評量碼**：GN3330500E
- **對應成功準則**：3.3.5
- **對應認證等級**：AAA
- **對應國際技術碼**：G71
- **類別**：General
- **訊息**：在所有網頁上均提供協助
- **英文訊息**：G71: Providing a help link on every Web page / G193: Providing help by an assistant in the Web page

## 規則說明
任何提供至少一個有幫助的連結資訊的網頁，都必須要遵守此指引。

## 檢測說明
使用chrome開啟檔案，"參考連結"部分會提供有幫助的連結資訊。 點選"參考連結"，檢查連結"參考連結"字體部分是否提供有幫助的資訊連結，這邊以https://www.w3.org/TR/WCAG20-TECHS/G71.html為例。 檢查原始碼，"參考連結"所提供的連結。
