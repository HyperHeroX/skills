# HM3330500C 使用標題屬性來提供針對脈絡而作的協助說明

- **檢測碼**：HM3330500C
- **對應成功準則**：3.3.5
- **對應認證等級**：AAA
- **對應國際技術碼**：H89
- **類別**：HTML
- **訊息**：使用標題屬性來提供針對脈絡而作的協助說明
- **英文訊息**：H89: Using the title attribute to provide context-sensitive help

## 規則說明

1. 檢查是否有文字輸入標籤。
2. 確認元件有使用到 label 標籤。
3. 確認 title 屬性中有提供針對脈絡的協助說明。

## 範例

```html
<label for="searchAddress">Address: </label>
<input id="searchAddress" type="text" size="30" value="" name="searchAddress"
  title="Address example: 101 Collins St, Melbourne, Australia" />
```

## 說明

地址輸入元件存在可對應的 label 標籤，和使用 title 屬性提供填寫補助說明。
