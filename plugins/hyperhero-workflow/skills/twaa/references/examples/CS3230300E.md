# CS3230300E 使用CSS媒體查詢(media query)的(reduce-motion)屬性避免畫面動態

- **稽核評量碼**：CS3230300E
- **對應成功準則**：2.3.3
- **對應認證等級**：AAA
- **對應國際技術碼**：C39
- **類別**：CSS
- **訊息**：使用CSS媒體查詢的reduce-motion避免畫面動態
- **英文訊息**：C39: Using the CSS reduce-motion query to prevent motion

## 規則說明

允許使用者透過使用"prefers-reduced-motion"的CSS媒體查詢(Media Query)來防止動畫顯示在網頁上。

## 檢測說明

**程序**

對於因使用者互動操作而動作的每個互動元素：

1. 啟用系統中的"減少運動"(Reduce Motion)設定；
2. 檢查動作為非必要性；
3. 檢查此元素無動作。

**預期結果**

#2和#3為是。
