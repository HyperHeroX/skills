# GN3220500E 儲存資料以便使用者重新認證後仍可使用

- **稽核評量碼**：GN3220500E
- **對應成功準則**：2.2.5
- **對應認證等級**：AAA
- **對應國際技術碼**：G105
- **類別**：General
- **訊息**：儲存資料以便使用者重新認證後仍可使用。
- **英文訊息**：G105: Saving data so that it can be used after a user re-authenticates

## 規則說明

需要用戶身份驗證的網站，在使用者在登入後填寫的表單(form)，萬一session時間超過設定時間而被登出，則使用者再次登入，其編輯的表單需可儲存先前的編輯內容。

## 檢測說明

1. 登錄並開始計時。
2. 允許SESSION超時。
3. 提交內容。
4. 重新認證。
5. 檢查此過程可以繼續且沒有遺失先前編輯的內容，包括原始資料和經過重新驗證所作的任何選擇。
