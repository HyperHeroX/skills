# GN1250400E 為動作啟動輸入提供常規控制元件和應用程式設定

- **稽核評量碼**：GN1250400E
- **對應成功準則**：2.5.4
- **對應認證等級**：A
- **對應國際技術碼**：G213
- **類別**：General
- **訊息**：為動作啟動輸入提供常規控制元件和應用程式設定
- **英文訊息**：G213: Provide conventional controls and an application setting for motion activated input

## 規則說明
本技術的目的是確保：
- 使用安裝的裝置或無法精確操作裝置的人可以通過更常規的使用者介面組件提供輸入。
- 可能由於震動或其他運動障礙而意外啟動感應器的人可以關閉動作啟動功能，以防止意外觸發功能。

當使用諸如加速度計或陀螺儀之類的裝置感應器來收集輸入時：
- 提供不依賴感應器輸入的按鈕、鏈結或其他常規控制元件。
- 提供允許使用者關閉感應器資料的設定。

## 檢測說明
程序

對於可響應運動感應器執行功能的每個輸入：
- 檢查是否存在不依賴感應器執行相同功能的機制。
- 檢查是否存在可關閉動作偵測的使用者設定。

預期結果：檢查#1和#2為是。
