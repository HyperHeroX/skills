# HM3240900C 任何具有連結目的之單獨鏈結組件均需有鏈結文字及標題屬性，且鏈結文字之內容及標題屬性之值均不得為空字串或空白

- **檢測碼**：HM3240900C
- **對應成功準則**：2.4.9
- **對應認證等級**：AAA
- **對應國際技術碼**：H33
- **類別**：HTML
- **訊息**：任何具有連結目的之單獨鏈結組件均需有鏈結文字及標題屬性，且鏈結文字之內容及標題屬性之值均不得為空字串或空白
- **英文訊息**：H33: Supplementing link text with the title attribute

## 規則說明

如果鏈結文字及標題屬性存在且不得為空字串或空白，通過檢測，否則檢測失敗。

## 範例

若 `<a>` 標籤內的 href 屬性與連結文字不為空值，且存在 title 屬性，則通過檢測。

## 說明

`<a>` 標籤若 href 屬性指定鏈結的目標，表示該連結是一個有效連結，必須要有可以識別的連結文字，並用 title 屬性補充連結的描述說明與用途。
