# HM1410201C 頁框組件及內嵌式頁框組件需有標題屬性，且其值不得為空字串或空白

- **檢測碼**：HM1410201C
- **對應成功準則**：4.1.2
- **對應認證等級**：A
- **對應國際技術碼**：H64
- **類別**：HTML
- **訊息**：頁框組件及內嵌式頁框組件需有標題屬性，且其值不得為空字串或空白
- **英文訊息**：H64: Using the title attribute of the frame and iframe elements

## 規則說明

如果 `<frame>` 或 `<iframe>` 標籤內 title 屬性存在且值不為空，通過檢測，否則檢測失敗。

## 範例

**範例1：frameset 頁框**
```html
<html xmlns="https://www.w3.org/1999/xhtml">
<head>
  <title>此文件的頁框</title>
</head>
<frameset cols="10%, 90%">
  <frame src="nav.html" title="主視窗" />
  <frame src="doc.html" title="文件" />
  <noframes>
    <body>
      <a href="lib.html" title="Library link">選擇去電子圖書館</a>
    </body>
  </noframes>
</frameset>
</html>
```

**範例2：iframe 內嵌頁框**
```html
<html xmlns="https://www.w3.org/1999/xhtml">
<head>
  <title>此文件的頁框</title>
</head>
<body>
  ...
  <iframe src="banner-ad.html" id="testiframe" name="testiframe" title="廣告"></iframe>
  ...
</body>
</html>
```

## 說明

**範例1**：將視窗分割成兩個子視窗，各自載入不同網頁內容並以 title 屬性說明子視窗用途，並在 `<noframes>` 中提供替代內容。

**範例2**：在網頁內內置一個框架，並提供 title 屬性標示此為廣告的頁框內容。
