# HM1110103E 圖片無法以替代文字清晰表達時，利用長描述提供更詳盡的說明

- **稽核評量碼**：HM1110103E
- **對應成功準則**：1.1.1
- **對應認證等級**：A
- **對應國際技術碼**：G73、G74、ARIA15
- **類別**：HTML
- **訊息**：圖片無法以替代文字清晰表達時，利用長描述提供更詳盡的說明網頁網址，利用整個說明網頁的篇幅來詳盡描述，最後並要能連結回原本的圖片
- **英文訊息**：G73: Providing a long description in another location with a link to it that is immediately adjacent to the non-text content / G74: Providing a long description in text near the non-text content / ARIA15: Using aria-describedby to provide descriptions of images

## 規則說明

任何運用 HTML 或 XHTML 提供長描述的網頁，都必須要遵守此指引。

## 範例

**範例1：長條圖**

網頁上有一個長條圖，顯示了排名前三的銷售人員的銷售額。短文本替代內容為「十月份前三名銷售人員的銷售額圖表。詳情請見圖表後的文字：」，圖表下方的段落則詳述各銷售人員的數據。

**範例2：標題用作鏈接**

圖表正下方的圖例標題是指向詳細描述的連結，連結的 title 屬性清楚表明這是指向詳細描述的連結。

**範例3：使用 aria-describedby 描述影像**

```html
<img alt="Lady MacBeth" src="ladymacbeth.jpg" aria-describedby="p1">
<p id="p1">This painting dates back to 1889 and is oil on canvas.
It was created by John Singer Sargent, and represents ...</p>
```

## 檢測程序

1. 檢查非文字內容之前或之後是否存在連結。
2. 檢查該連結是否為有效連結，並直接指向該特定非文本內容的詳細描述。
3. 檢查長描述是否傳達與非文字內容相同的訊息。
4. 檢查連結或返回功能的可用性，以便讓使用者返回非文字內容的原始位置。
