# GN1250100E 提供單點指標控制元件以實現與基於路徑或多點手勢相同的結果

- **稽核評量碼**：GN1250100E
- **對應成功準則**：2.5.1
- **對應認證等級**：A
- **對應國際技術碼**：G215
- **類別**：General
- **訊息**：提供單點指標控制元件以實現與基於路徑或多點手勢相同的結果
- **英文訊息**：G215: Providing controls to achieve the same result as path based or multipoint gestures

## 規則說明
基於路徑的手勢時，透過提供控制元件(例如，箭頭按鈕)作為替代輸入方式。 注意： 在觸控螢幕裝置上，當打開內置螢幕報讀軟體之類的OS級輔助技術(AT)時，由網頁作者提供的基於路徑的手勢通常無作用。

## 檢測說明
程序

對於基於路徑手勢的內容滑塊：
檢查單點指標可操作控制元件在內容滑塊上方或附近是否存在，且控制元件推動相鄰組成的內容。

預期結果：#1為是。

無
