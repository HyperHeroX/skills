# CS3140802C 需有CSS樣式規則指定行距

- **檢測碼**：CS3140802C
- **對應成功準則**：1.4.8
- **對應認證等級**：AAA
- **對應國際技術碼**：C21
- **類別**：CSS
- **訊息**：需有CSS樣式規則指定行距
- **英文訊息**：C21: Specifying line spacing in CSS

## 規則說明

如果某標籤內有文字內容且在 CSS 中存在此標籤的行距設定，通過檢測，否則檢測失敗。

## 範例

```html
<!-- HTML -->
<p>文章內容</p>
```
```css
/* CSS */
p { line-height: 150%; }
```

## 說明

`<p>` 標籤的樣式規則設定行距高度為預設值的 150%，即將文章段落內的行距放大到原本的 150%。
