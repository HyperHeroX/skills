# HM1310100C 網頁根組件需有語言屬性，且其值必須合於指引，不得為空字串或空白

- **檢測碼**：HM1310100C
- **對應成功準則**：3.1.1
- **對應認證等級**：A
- **對應國際技術碼**：H57
- **類別**：HTML
- **訊息**：網頁根組件需有語言屬性，且其值必須合於指引，不得為空字串或空白
- **英文訊息**：H57: Using language attributes on the html element

## 規則說明

如果 `<html>` 標籤中有 lang 屬性存在且值不為空，通過檢測，否則檢測失敗。

## 範例

```html
<!DOCTYPE>
<html lang="zh-Hant-TW">
<head>
  <meta charset="utf-8">
  <title>國家通訊傳播委員會 無障礙網路空間服務網</title>
</head>
<body>
  ...以正體中文表示的內容...
</body>
</html>
```

## 說明

以正體中文編寫的網頁內容，在 `<html>` 標籤內以 lang 屬性將整份內容標示為 zh-Hant-TW 網頁。
