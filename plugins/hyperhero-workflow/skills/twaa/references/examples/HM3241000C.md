# HM3241000C 網頁必須要使用標頭組件

- **檢測碼**：HM3241000C
- **對應成功準則**：2.4.10
- **對應認證等級**：AAA
- **對應國際技術碼**：G141
- **類別**：HTML
- **訊息**：網頁必須要使用標頭組件
- **英文訊息**：G141: Organizing a page using headings

## 規則說明

如果標頭組件存在，通過檢測，否則檢測失敗。

## 範例

```html
<body>
  <h1>烹飪技術</h1>
  ... 這裡一些文字 ...
  <h2>使用油烹調</h2>
  ... 部分的文字 ...
  <h3>清炒</h3>
  ... 
  <h3>油炸</h3>
  <h2>用奶油烹調</h2>
  ... 部分的文字 ...
</body>
```

## 說明

`<h1>`～`<h6>` 標籤可定義標題，`<h1>` 標籤定義最大的標題，`<h6>` 標籤定義最小的標題。
