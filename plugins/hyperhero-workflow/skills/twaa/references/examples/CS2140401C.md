# CS2140401C 任何CSS樣式規則均使用具名字型尺寸，或者使用百分比或em等相對字型尺寸單位

- **檢測碼**：CS2140401C
- **對應成功準則**：1.4.4
- **對應認證等級**：AA
- **對應國際技術碼**：C12、C13、C14
- **類別**：CSS
- **訊息**：任何CSS樣式規則均使用具名字型尺寸，或者使用百分比或em等相對字型尺寸單位
- **英文訊息**：C12: Using percent for font sizes / C13: Using named font sizes / C14: Using em units for font sizes

## 規則說明

如果 CSS 樣式內存在 font-size 屬性且使用具名或相對（如使用百分比或 em）的字型尺寸，通過檢測，否則檢測失敗。

## 範例

**範例1：使用 em 相對單位**
```css
strong { font-size: 1.6em }
```

**範例2：使用具名字型尺寸**
```css
strong { font-size: larger }
```

**範例3：使用百分比**
```css
strong { font-size: 120% }
```

HTML 搭配使用：
```html
<h1>讓<strong>使用者</strong>控制文字尺寸</h1>
<p>讓使用者能知道如何控制文字尺寸是<strong>非常</strong>重要的</p>
```

## 說明

- **範例1**：CSS 樣式規則使用了 em 相對字型尺寸單位。
- **範例2**：CSS 樣式規則使用了 larger 具名字型尺寸單位。
- **範例3**：CSS 樣式規則使用了百分比相對字型尺寸單位。
