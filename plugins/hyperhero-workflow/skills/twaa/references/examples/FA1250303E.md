# FA1250303E 由於無障礙名稱不包含可見標籤文字而導致失敗

- **稽核評量碼**：FA1250303E
- **對應成功準則**：2.5.3
- **對應認證等級**：A
- **對應國際技術碼**：F96
- **類別**：Failure
- **訊息**：由於無障礙名稱不包含可見標籤文字而導致失敗
- **英文訊息**：F96: Failure due to accessible name not containing the visible label text

## 規則說明
如果可見標籤與控制元件的無障礙名稱不匹配，則語音用戶可能無法直接啟動該控制元件。

## 檢測說明
程序

對於具有可見標籤的所有控制元件(例如，鏈接文字、按鈕文字、以編程方式鏈結的標籤、帶有文字的鏈結中的圖片)：
- 無障礙的名稱與可見標籤相同。
- 無障礙名稱包含可見標籤字符串的匹配項。

預期結果：如果檢查#1和#2為否，則符合失敗條件，此內容未通過成功準則。
