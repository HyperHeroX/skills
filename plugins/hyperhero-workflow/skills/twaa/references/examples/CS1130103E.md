# CS1130103E 文字的視覺呈現均以CSS來控制

- **稽核評量碼**：CS1130103E
- **對應成功準則**：1.3.1
- **對應認證等級**：A
- **對應國際技術碼**：C22
- **類別**：CSS
- **訊息**：文字的視覺呈現均以CSS來控制
- **英文訊息**：C22: Using CSS to control visual presentation of text

## 規則說明

需要用到CSS樣式表來改變文字呈現方式時，且皆須遵守此指引。

## 檢測說明

使用Google Chrome瀏覽器開啟檔案，確認是否有受CSS樣式表影響文字視覺呈現。(此範例顯示文字靠右及顯示背景色)

點選右鍵檢視網頁原始碼。

程式碼中我們可以看到以CSS樣式表控制文字視覺呈現。

## 說明

無
