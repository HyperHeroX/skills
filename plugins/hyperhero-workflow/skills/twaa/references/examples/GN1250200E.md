# GN1250200E 確保可以取消拖放操作

- **稽核評量碼**：GN1250200E
- **對應成功準則**：2.5.2
- **對應認證等級**：A
- **對應國際技術碼**：G210
- **類別**：General
- **訊息**：確保可以取消拖放操作
- **英文訊息**：G210: Ensuring that drag-and-drop actions can be cancelled

## 規則說明
此技術的目的是確保使用基於路徑的拖放(drag-and-drop)操作將項目從初始位置移動到放置目標，使用者可以在拾取目標後中止操作。可透過在放置區域外釋放項目，或者將項目移回其原始位置來完成。第三個選項是在元素被放到目標上之後，提供刪除或取消。

## 檢測說明
程序

對於可拖動的內容，檢查拖放操作是否可以透過以下方式撤銷：
- 將拾取物品於預計放下的目標外放下
- 將拾取的物品拖回原始的位置
- 刪除項目後會出現確認對話框或撤銷控制元件

預期結果：#1、#2、#3中至少有一個選項為是。
