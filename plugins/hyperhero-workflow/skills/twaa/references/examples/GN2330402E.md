# GN2330402E 在法律、財務、個人資料方面，均提供使用者在送出答覆前加以檢查及更正的能力

- **稽核評量碼**：GN2330402E
- **對應成功準則**：3.3.4
- **對應認證等級**：AA
- **對應國際技術碼**：G98
- **類別**：General
- **訊息**：在法律、財務、個人資料方面，均提供使用者在送出答覆前加以檢查及更正的能力
- **英文訊息**：G98: Providing the ability for the user to review and correct answers before submitting

## 規則說明
檢查在購物網站送出訂單前是否有檢查及更正的能力。

## 檢測說明
網站是否有再次審查資料的功能。

## 說明
無
