# ME1320200C 提供下載之檔案格式應為開放格式如ODF、PDF、HTML等檔案格式

- **檢測碼**：ME1320200C
- **對應成功準則**：3.2.2
- **對應認證等級**：A
- **類別**：媒體
- **訊息**：提供下載之檔案格式應為開放格式如ODF、PDF、HTML等檔案格式

## 規則說明

如果 `<a>` 標籤內 href 屬性值為含有檔案名稱的 URL，則其副檔名應為 ODF 格式（含 ODT、ODS、ODP 等）、PDF 等。

## 範例

**範例1：提供同一檔案不同類型的下載方式**
```html
<ol>
  <li>
    <span>107年度11月份重要統計資料手冊</span>
    <ul>
      <li><a href="...手冊.odt" target="_blank" title="[開新分頁下載]107年度11月份重要統計資料手冊.odt"><span class="odt">odt</span></a></li>
      <li><a href="...手冊.pdf" target="_blank" title="[開新分頁下載]107年度11月份重要統計資料手冊.pdf"><span class="pdf">pdf</span></a></li>
      <li><a href="...手冊.doc" target="_blank" title="[開新分頁下載]107年度11月份重要統計資料手冊.doc"><span class="doc">doc</span></a></li>
    </ul>
  </li>
</ol>
```

**範例2：提供 ODT 檔案下載**
```html
<a href="homework1.odt">習題 (odf格式)</a>
```

## 說明

**範例1**：對同一檔案提供多種格式（ODT、PDF、DOC）下載，讓使用者依需求選擇。

**範例2**：網頁上顯示「習題 (odf格式)」的文字連結，點擊該連結會下載或開啟一個 ODF 格式的檔案。
