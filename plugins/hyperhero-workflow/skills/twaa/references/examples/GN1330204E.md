# GN1330204E 使用毗鄰的按鈕來標示輸入區目的

- **稽核評量碼**：GN1330204E
- **對應成功準則**：3.3.2
- **對應認證等級**：A
- **對應國際技術碼**：G167
- **類別**：General
- **訊息**：使用毗鄰的按鈕來標示輸入區目的
- **英文訊息**：G167: Using an adjacent button to label the purpose of a field

## 規則說明
任何在HTML或XHTML的網頁內，如果輸入區毗鄰著按鈕，按鈕上面必須要有文字說明輸入區的目的。

## 檢測說明
檢查相鄰的輸入區和按鈕，按鈕上面必須有文說明輸入區的目的。

## 說明
無
