## 檔案命名規則

格式：`[類別前綴][等級][成功準則][序號][類型].md`

- **類別前綴**：AR(ARIA)、CS(CSS)、FA(Failure)、GN(General)、HM(HTML)、ME(Media)、SC(Script)
- **等級**：1(A)、2(AA)、3(AAA)
- **成功準則**：如 110100 = 1.1.1
- **類型**：C(檢測碼)、E(稽核評量碼)
