# 原圖形式 → 重繪形式對照

重繪配圖的第一原則：**沿用原始資料（影片畫面、原投影片、板書）的結構與構圖邏輯**，只換掉風格。
同一份簡報裡的圖不該長得一樣；如果十張圖都是「一排圓角卡片＋箭頭」，就是沒有對照原圖。

| 原圖長這樣 | 重繪成 | layout | 要點 |
|---|---|---|---|
| 同心圓、洋蔥、城堡、縱深防禦 | 同心圓或同心弧，核心用 NAVY 實心圓 | side | 每層一色（C 固定順序）；層名放在兩弧之間並加 `knockout()` 白底；上下或內外可分別放「角色／控制」 |
| 協定往返、握手、認證流程（Kerberos、TLS） | 時序圖：每個參與者一條垂直生命線，訊息為水平箭頭 | side 或 full | 參與者頂端用 `badge()`；訊息依序由上而下；回應用虛線 |
| OSI / TCP/IP / 分層架構 | 水平疊層，左右可加對照欄 | side | 每層一條色帶；跨層的東西用垂直括號標示 |
| 生命週期、循環（PDCA、IR、SDLC） | 環狀：節點等距排在圓周，弧形箭頭相接 | side | 起點在 12 點鐘方向；中心放循環名稱 |
| 多站線性流程（金鑰生命週期、證據保管鏈） | 橫向時間軸：主幹線＋圓形站點＋下方說明卡 | full | 站名在上、說明在下；站點用 `circle` 主色＋白色 `icon` |
| 決策流程、考試／申請程序 | 流程圖：方框＋菱形判斷＋折線箭頭 | side | 是／否分支用不同顏色並標字；終點用 NAVY 實心框 |
| 2×2 矩陣（風險、影響×可能性） | 四象限，軸線標高低 | side | 象限用 TINT 填色；最重要象限用主色框強調 |
| 光譜、程度（Open → Closed、DAC → MAC） | 水平光譜條＋刻度標記 | full | 兩端標極值；項目以標記點落在光譜上 |
| 比較、優缺點、A vs B | 左右對照兩欄或天平 | side | 兩邊用 C[0]／C[1]；中間放比較維度 |
| 階層、組織、分類樹 | 樹狀：根在上，折線連到子節點 | side 或 full | 同層等高；葉節點多時改橫向 |
| 包含關係、交集 | 維恩圖或巢狀框 | side | 交集區域用文字標示，不用混色 |
| 網路拓撲（DMZ、分段） | 區域框（虛線）＋設備圖示＋連線 | full | 區域用 TINT 填色；信任邊界用粗虛線 |
| 公式（ALE = SLE × ARO） | 公式卡：每個項目一個色塊，運算子放大 | side | 每個變數下方寫中文定義與單位 |
| 數量比較、天數、時程 | 長條（橫向）＋數值標在條內 | side | 只有一個量就不用圖例；長條起點對齊 |
| 原圖只有文字條列 | 依內容關係自選上表一種形式 | — | 真的沒有關係結構就**不要硬畫**，改用條列卡片版面 |

## 取得原圖

- 有影片：`python3 scripts/extract_frames.py <影片> <起> <迄>` → 用 Read 看 `sheet.jpg`，需要細節再看單張。
- 有原投影片／PDF：轉成圖片後用 Read 看對應頁。
- 原圖不清楚或內容有誤：結構照原圖，文字與事實以使用者的筆記內容為準，不自行增加事實。
