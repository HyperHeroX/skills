# 設計代號與版面規範

## 色票（已用 dataviz 技能的 `validate_palette.js` 驗證，亮色模式全數 PASS）

| 用途 | 色碼 | 說明 |
|---|---|---|
| 類別色 C[0]…C[5] | `#2468C0` 藍、`#D2581F` 橘、`#14906A` 綠、`#A97800` 金、`#C0427A` 桃、`#5B47C4` 紫 | **固定順序**指派：第一類 C[0]、第二類 C[1]…不跳色、不循環。超過 6 類 → 合併成「其他」或拆圖 |
| 淡底 TINT[0]…[5] | `#DCE8F7`、`#FBE3D5`、`#D5EFE5`、`#F5EACB`、`#F7DDE9`、`#E4E0F6` | 與 C 同索引搭配：淡底填色＋主色 3px 框線 |
| INK | `#12202E` | 主文字（所有長文字） |
| BODY | `#2A3747` | 次文字 |
| MUTED | `#4A5664` | 註解、圖例 |
| NAVY | `#1B2B3F` | 結構：主幹、核心、標題列、時間軸 |
| LINE | `#5B6775` | 一般連線、箭頭 |
| GRID | `#C9D1D9` | 淡分隔線 |
| HL | `#FFE58A` | 重點螢光底（PPT 文字 highlight） |

換品牌色時：把新色票丟進 dataviz 驗證器（`node scripts/validate_palette.js "<hex,...>" --mode light`），
相鄰色色盲 ΔE ≥ 8、一般視覺 ΔE ≥ 15、對比通過後，再替換 svgkit.py 開頭的 C/TINT。其餘程式不用改。

### 顏色只用來編碼
- 同一個意義在整份簡報用同一個顏色（例：威脅一律橘、控制一律綠、資料核心一律 NAVY）。
- 類別色只用在**短標籤、線條、色塊、圖示**；長句一律 INK/BODY，不用彩色字。
- 不要漸層、不要裝飾性色條或邊條、不要彩虹。

## 字

| 層級 | 字級（px） | 粗細 |
|---|---|---|
| 主標籤（站名、層名、節點名） | 28–34 | 700 |
| 一般標籤 | 24–28 | 400–700 |
| 說明、註解、圖例 | 22–24 | 400 |
| 下限 | **22**（≈ 投影片 11pt） | — |

- 圖內**不放大標題**（投影片已有標題）。
- 不用全大寫英文標籤；術語保留英文原文（如 Key Wrapping、Need to Know）。
- 只有內容真的是順序時才加編號。

## 版面（LAYOUT_WIDE，1 in = 144 px）

| layout | 畫布寬 | 適合 | 投影片配置 |
|---|---|---|---|
| `side` | 1048 px | 直式、方形結構：同心圓、樹、堆疊、2×2、維恩、時序圖 | 條列在左、圖在右 |
| `full` | 1747 px | 橫向長流程、寬時間軸、多站生命週期 | 圖全寬置中、條列在下方兩欄 |

- 高度：side 通常 ≤ 615 px；full 依條列多寡 300–520 px。
- 邊距 ≥ 10 px；箭頭尖端不壓文字；元素間距 ≥ 16 px。
- 每張圖下方加一行 caption「看圖重點：…」（≤ 40 字），說出這張圖要讀者帶走的那一件事。

## 投影片文字重點標示

- 在筆記資料中用 `**詞**` 標記關鍵詞，組 PPT 時轉成**粗體＋黃色螢光底 FFE58A**。
- 「關鍵詞：說明」格式的條列，關鍵詞用類別色粗體，並與配圖中同一概念的顏色一致。
- 一個條列最多 1–2 個標記，避免整段都是黃色。
